## FAQs about reinforcing mesh suppliers

### What is the difference between reo mesh and trench mesh?

Reo mesh is a broad term for reinforcing mesh used in concrete. Trench mesh is a narrower reinforcing product designed for footings, beams and structural bases. Square and rectangular mesh are usually used in larger slab or panel areas, while trench mesh suits narrow concrete elements.

### What is wire mesh for a concrete slab?

Wire mesh for a concrete slab usually refers to welded reinforcing mesh placed within the concrete to help control cracking and improve tensile performance. In Australia, slab mesh is commonly described using SL or RL product names, depending on the mesh pattern and bar size.

### Which trench mesh size should I use?

Use the trench mesh size specified by the engineer or slab design. Common Australian trench mesh products include 3-bar, 4-bar, 5-bar and 6-bar configurations, with different bar diameters. Do not substitute a trench mesh size without approval.

### Should I choose the cheapest steel mesh supplier?

Price matters, but the cheapest quote can become expensive if stock is late, the order is incomplete, or the delivery cannot be unloaded safely. Compare product range, availability, scheduling support, delivery planning and responsiveness as well as cost.
