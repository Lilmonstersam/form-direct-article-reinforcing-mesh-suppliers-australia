# Form Direct Article Mockup: Reinforcing Mesh Suppliers Australia

Static article page mockup for the Form Direct article "Reinforcing Mesh Suppliers in Australia".

## Repository

- GitHub repo: https://github.com/Lilmonstersam/form-direct-article-reinforcing-mesh-suppliers-australia.git
- Expected GitHub Pages URL: https://lilmonstersam.github.io/form-direct-article-reinforcing-mesh-suppliers-australia/

## Files

- `index.html` - Navigation-friendly article page mockup.
- `form-direct-article-mockup.css` - Shared Form Direct article mockup styling.
- `reinforcing-mesh-suppliers-australia.md` - SEO article copy used for the mockup.
- `README.md` - Repo documentation and file map.
- `.nojekyll` - Allows GitHub Pages to serve the static files without Jekyll processing.
- `.github/workflows/deploy.yml` - GitHub Actions workflow that publishes the static mockup to GitHub Pages.

## Notes

- The page is a static HTML mockup and can be hosted directly from the repo root.
- External images, product links, project links, and the Form Direct logo are referenced from `formdirect.com.au`.
- The mockup includes a sticky contents sidebar, contextual CTAs, product/internal links, and responsive layout styles.

## Local Preview

Open `index.html` in a browser, or serve the folder with any static server.

## Deployment

Pushing to `main` runs the GitHub Pages workflow. In the GitHub repo, go to **Actions** to view the deployment run and **Settings > Pages** to confirm the live Pages URL.
